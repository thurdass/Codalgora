# Codalgora v0.3.0 — Windows e Linux

O Codalgora v0.3.0 amplia a IDE com o Construtor Visual: crie formulários JavaFX, conecte controles a variáveis e procedimentos Portugol e exporte aplicativos independentes.

## Novidades

- Editor visual com paleta pesquisável, canvas, árvore de componentes, edição de propriedades e organização responsiva.
- Controles de texto, botão, campo e área de texto, caixa de seleção e lista suspensa.
- Vínculos entre controles e variáveis globais Portugol; ações executam procedimentos e atualizam os valores exibidos.
- Edição com desfazer/refazer, persistência JSON validada, estilos visuais e exemplo de contador.
- Exportação do formulário e algoritmo como aplicativo portátil com runtime Java para a plataforma atual.
- Menu Créditos com QR Pix para contribuição voluntária.

## Downloads

- Windows x64: instalador MSI (recomendado) e EXE.
- Linux x64 (Debian/Ubuntu): pacote DEB.
- `SHA256SUMS.txt`: hashes SHA-256 dos instaladores.

O [workflow da release 44978474153](https://github.com/thurdass/Codalgora/actions/runs/44978474153) passou em Linux e Windows. Os instaladores foram gerados e exercitados nos dois sistemas; os hashes SHA-256 foram conferidos antes da publicação.

Arquivos publicados: `codalgora_0.3.0_amd64.deb`, `Codalgora-0.3.0.msi`, `Codalgora-0.3.0.exe` e `SHA256SUMS.txt`.
